# تواصل PRO - مشروع APK حقيقي

هذا هو الكود الكامل لتطبيق "تواصل" اللي طلبته:
- تسجيل دخول Google أصلي (يطلع حسابات الجيميل الموجودة بتلفونك)
- دردشة 1-1
- كروبات خاصة
- منشورات وستوري
- يعمل على أندرويد

## شلون تطلع APK خلال 10 دقايق:

1. نزل Flutter من flutter.dev
2. افتح التيرمنال في مجلد المشروع وشغل:
   flutter pub get
3. روح Firebase Console وسوي مشروع جديد، فعل Authentication > Google
4. نزل ملف google-services.json وحطه في android/app/
5. شغل:
   flutter build apk --release

الـ APK راح يطلع في: build/app/outputs/flutter-apk/app-release.apk

إذا ما عندك كمبيوتر، ارفع المشروع على GitHub واستخدم Codemagic.io (مجاني) يبني APK بالسحابة ويدزلك رابط تحميل.

النسخة الحالية فيها واجهة تسجيل Google جاهزة، ومن تدوس عليها بأي تلفون أندرويد راح تطلعلك حساباتك الحقيقية.

تحتاج مساعدة بالخطوات؟ كلي وانا أمشي وياك خطوة خطوة.
